LEE YEEUN Portfolio Site

사용 방법
1. index.html을 더블클릭하면 포트폴리오 페이지가 열립니다.
2. 영상 삽입:
   - carrotpad_showreel.mp4 파일을 같은 폴더에 넣고,
   - index.html의 SHOWREEL VIDEO 영역을 video 태그로 교체하면 됩니다.
   예시:
   <video controls autoplay muted loop playsinline>
     <source src="carrotpad_showreel.mp4" type="video/mp4">
   </video>

3. Process 이미지 삽입:
   - 이미지 파일을 같은 폴더에 넣고,
   - image-placeholder 영역을 img 태그로 교체하면 됩니다.
   예시:
   <img src="process01.jpg" alt="Storyboard">

4. 실제 웹 링크로 만들려면 Netlify, Vercel, GitHub Pages, 카페24, Wix 등에 업로드하면 됩니다.
